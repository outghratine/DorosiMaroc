# موقع دروسي - موقع تعليمي احترافي

موقع ويب تعليمي احترافي مشابه لموقع dorossy.com مصمم بتقنيات HTML5, CSS3, و JavaScript.

## المميزات

### التصميم
- تصميم عصري واحترافي بألوان جذابة
- واجهة مستخدم سهلة الاستخدام
- تصميم متجاوب (Responsive) يعمل على جميع الأجهزة
- تأثيرات حركية سلسة وجذابة

### الأقسام الرئيسية
- **الصفحة الرئيسية**: عرض أحدث المقالات والمشاركات
- **قائمة التنقل**: أقسام متعددة (تعليم ابتدائي، إعدادي، ثانوي، جامعي، وظائف، إدارة، تكوينات)
- **الشريط الجانبي**: روابط سريعة للأقسام والفئات
- **صفحات المقالات**: صفحات تفصيلية للمقالات مع نظام تعليقات
- **شريط الأخبار**: عرض آخر المستجدات بشكل متحرك

### الميزات التقنية
- شريط تقدم القراءة
- زر العودة للأعلى
- نظام مشاركة على وسائل التواصل الاجتماعي
- تحميل الصور بشكل تدريجي (Lazy Loading)
- قائمة تنقل ثابتة عند التمرير
- نظام بحث تفاعلي
- نظام تعليقات للمقالات
- مقالات ذات صلة
- قسم المقالات الأكثر قراءة

## البنية

- **الأزرق الداكن**: `#1a1a4d` - للهيدر والقوائم

- **الرمادي الفاتح**: `#f9fafb` - للخلفيات
- **الأبيض**: `#ffffff` - للبطاقات والمحتوى

## المتطلبات

## التشغيل

1. افتح ملف `index.html` في المتصفح
2. للتنقل إلى صفحة مقال، افتح `post1.html`

## التخصيص

### تغيير الألوان
يمكنك تغيير الألوان من خلال تعديل المتغيرات في ملف `style.css`:

```css
:root {
    --primary-color: #1a1a4d;
    --secondary-color: #2563eb;
    --accent-color: #14b8a6;
    /* ... */
}
```

### إضافة مقالات جديدة
1. انسخ ملف `post1.html`
2. عدّل المحتوى حسب الحاجة
3. أضف رابط المقال في الصفحة الرئيسية

### تعديل القوائم
عدّل قوائم التنقل في ملفات HTML:
- القائمة العلوية في `.top-nav`
- القائمة الرئيسية في `.nav-menu`
- القوائم الجانبية في `.sidebar`

## ملاحظات

- الموقع مصمم بشكل ثابت (Static) ولا يحتاج إلى قاعدة بيانات
- الصور المستخدمة هي صور نموذجية من placeholder.com
- يمكن استبدال الصور بصور حقيقية
- نظام التعليقات يحتاج إلى backend لحفظ البيانات
- يمكن ربط الموقع بنظام إدارة محتوى مثل WordPress أو Blogger

## نصائح للاستخدام

1. **للاستخدام كمدونة شخصية**: قم بتعديل المحتوى والصور حسب احتياجاتك
2. **للاستخدام التجاري**: أضف Google Analytics و Google AdSense
3. **للأداء الأفضل**: استضف الخطوط والأيقونات محلياً بدلاً من CDN
4. **للسيو (SEO)**: أضف meta tags مناسبة لكل صفحة
